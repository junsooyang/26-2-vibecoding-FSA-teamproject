# 팀플X실시간 협업 보드

> 아이디어를 모으고 → 정리하고 → 실제 할 일로 만드는 과정을, 팀원 모두가 **한 화면에서 실시간으로** 끝내는 팀 프로젝트 협업 도구입니다.

## 왜 만들었나요?

대학생 팀플은 보통 이렇게 흘러갑니다. 아이디어는 카톡에, 정리는 노션에, 일정은 캘린더에, 할 일은 엑셀에 흩어져 있고, 정작 **"그래서 누가 언제까지 뭘 하지?"** 에 닿기까지 시간이 많이 듭니다.

이 서비스는 그 흐름을 하나로 이어 줍니다.

- **흩어진 도구를 하나로.** 브레인스토밍, 마인드맵, 업무 분해(WBS), 일정, 투표, 채팅을 한 보드 안에서 해결합니다.
- **아이디어가 곧 할 일이 됩니다.** 채택한 아이디어를 버튼 한 번으로 담당자·마감일·진행률이 있는 작업으로 바꿉니다.
- **복잡하지 않게.** 처음 쓰는 팀원도 바로 참여할 수 있도록 단계별로 묶은 단순한 툴바를 씁니다.
- **동시에 편집해도 안전하게.** 여러 명이 같은 보드를 만져도 충돌 없이 자동으로 합쳐집니다.

## 핵심 흐름

```
① 브레인스토밍          ② 마인드맵 구조화            ③ WBS 작업 연결
아이디어 막 던지기  →  관련 아이디어 연결/정리  →  채택한 아이디어를 할 일로 "승격"
 + 메모 / 더블클릭      점끼리 드래그 + 정렬         → 작업으로 버튼
```

1. **아이디어 모으기** : 빈 곳을 더블클릭하거나 **+ 메모**로 떠오르는 생각을 자유롭게 적습니다.
2. **마인드맵으로 정리** : 노드의 점끼리 드래그해 연결하고, **가로/세로 정렬**로 트리처럼 구조화합니다.
3. **작업으로 전환** : 채택한 아이디어를 고르고 **→ 작업으로**를 누르면, 위치와 연결은 그대로 둔 채 WBS 작업이 됩니다.

툴바가 이 ①→②→③ 단계로 묶여 있고, 부가 기능은 **더보기** 뒤에 접혀 있습니다. 빈 보드에서는 3단계 안내가 표시됩니다.

## 주요 기능

### 아이디어 · 마인드맵
- **아이디어 노드** : 빈 캔버스를 더블클릭해 추가합니다. 여러 줄 입력을 지원합니다(저장은 Ctrl/⌘ + Enter).
- **스티커(포스트잇) 메모** : 제목과 내용, 4가지 색상(노랑/분홍/파랑/초록)을 지원합니다.
- **사진 노드** : 참고 이미지를 보드에 올립니다(최대 3MB).
- **연결과 정리** : 점끼리 드래그해 연결하거나, 노드를 다른 노드 위로 끌어다 놓아 부모-자식으로 **합칩니다**. 놓기 전에 "여기에 합치기" 안내가 표시됩니다.
- **자동 정렬** : 가로(→)·세로(↓) 트리로 정리하고, 격자(▦)로 줄맞춤합니다. 드래그할 때는 20px 그리드에 맞춰집니다.
- **보기 편의** : 노드 크기 조절, 긴 내용 접기/펼치기, 연결선 색상·굵기 설정(전원에게 공유), 미니맵.

### 작업 관리 (WBS)
- **아이디어 → 작업 승격** : 선택한 노드를 WBS 작업으로 바꿉니다. 텍스트, 투표, 댓글이 그대로 이어집니다.
- **작업 정보** : 작업명, 담당자, **마감일**, 상태(할 일/진행/완료), 진행률, 세부 체크항목을 관리합니다.
- **자료 첨부** : 링크나 파일(최대 2MB)을 작업에 붙입니다.
- **한 번에 완료** : 노드의 체크박스로 완료 처리하면 진행률이 100%가 되고 제목에 취소선이 표시됩니다.
- **마감 알림 표시** : 마감 3일 이내는 노랑, 지난 작업은 빨강으로 강조하고 `D-2`, `D-DAY`, `3일 지남`으로 표시합니다.
- **대시보드** : 전체 진행률, 상태별 작업 수, 지연 건수, **팀원별 업무 현황**을 한눈에 봅니다.

### 일정 · 의사결정
- **팀 캘린더** : 월별 달력에서 날짜별로 일정을 추가·수정·삭제·완료 체크합니다. 연/월 단위로 이동할 수 있습니다.
- **WBS 마감 자동 기록** : WBS에 마감일을 지정하면 캘린더 해당 날짜에 자동으로 나타납니다. 캘린더에서 체크하면 그 작업이 완료 처리되고, 마감일을 바꾸거나 작업을 지우면 캘린더에도 바로 반영됩니다.
- **투표 세션** : 질문과 선택지를 만들어 팀 투표를 진행합니다. 여러 주제를 동시에 열 수 있고, 마감 시각이 지나면 자동 종료되며, 결과는 실시간 막대그래프로 보입니다.
- **노드 투표** : 아이디어나 작업 카드의 👍 버튼으로 우선순위를 정합니다(1인 1표).

### 소통
- **방 채팅** : 같은 보드에 들어온 사람끼리 자유롭게 대화합니다. 오른쪽 위에 항상 떠 있는 💬 버튼으로 열고, **내가 보낸 메시지는 수정·삭제**할 수 있습니다.
- **노드 댓글** : 특정 아이디어나 작업에 의견을 남깁니다. 본인 댓글만 수정·삭제할 수 있습니다.
- **실시간 커서** : 다른 팀원의 마우스 위치가 이름표가 달린 색깔 커서로 보입니다.
- **접속 현황** : 지금 보드에 들어와 있는 팀원을 상단에서 확인합니다.

### 개인 공간 · 내보내기
- **개인 공간** : 나만 보는 노트장과 파일 보관함입니다. 서버에 저장되어 **다른 기기에서 로그인해도 그대로** 보입니다.
- **공유(내보내기)** : 더보기 › **공유**에서 보드 전체를 **이미지(PNG)** 또는 **PDF**로 저장합니다. 발표 자료나 회의록에 바로 붙일 수 있습니다.

### 보드 · 멤버 관리
- **보드 만들기** : 이름을 비워 두고 만들면 `새보드(1)`, `새보드(2)`…로 자동 이름이 붙습니다.
- **초대와 수락** : 팀장이 아이디로 팀원을 초대하면, 팀원이 **수락해야** 입장할 수 있습니다. 거절하면 초대가 사라집니다.
- **보드 삭제(팀장 전용)** : 확인 문구 `삭제하겠습니다.`를 직접 입력해야 삭제되어 실수를 막습니다. 보드 내용, 멤버, 모든 팀원의 개인 공간이 함께 지워지며 되돌릴 수 없습니다.

## 계정 & 권한

| 역할 | 권한 |
|------|------|
| **팀장 (owner)** | 보드 생성자. 멤버 초대/강퇴, **보드 삭제**, 편집 모두 가능 |
| **참여자 (member)** | 입장과 편집만 가능 (초대/삭제 불가) |
| **초대 대기 (invited)** | 초대는 받았지만 아직 수락 전. 입장 불가 |

- 로그인 식별자는 **아이디**(영문/숫자/밑줄, 3~20자)입니다. 인증은 JWT, 비밀번호는 bcrypt로 해싱해 저장합니다.
- 권한 검사는 **서버(API)** 에서 하므로, 초대받지 않은 사용자는 보드 데이터에 접근할 수 없고 참여자는 화면을 조작해도 보드를 삭제할 수 없습니다.

## 사용법 요약

| 하고 싶은 일 | 방법 |
|------|------|
| 아이디어 추가 | 빈 캔버스 **더블클릭** |
| 메모 추가 | 툴바 **+ 메모** |
| 작업(WBS) 추가 | 툴바 **+ WBS 작업** |
| 아이디어를 작업으로 | 노드 선택 후 **→ 작업으로** |
| 노드 연결 | 점(handle)끼리 드래그, 또는 노드를 다른 노드 위로 끌어다 놓기 |
| 노드 수정 | 노드 **더블클릭** (WBS는 편집 패널) |
| 삭제 | 선택 후 `Delete` |
| 마감일 지정 | WBS 편집 패널의 **마감일** → 캘린더에 자동 표시 |
| 캘린더 / 대시보드 / 투표 | 툴바 **더보기** 안의 각 버튼 |
| 보드를 이미지·PDF로 저장 | **더보기 › 공유** |
| 채팅 | 오른쪽 위 **💬 채팅** |
| 개인 공간 | 화면 왼쪽 가장자리 **🗂️ 탭** |
| 팀원 초대 | **더보기 › 멤버 관리** |
| 보드 삭제 | **더보기 › 🗑️ 보드 삭제** (팀장만 보임) |

## 기술 스택

| 영역 | 사용 기술 |
|------|-----------|
| 프론트엔드 | React 18 + TypeScript + Vite |
| 캔버스 / 노드 UI | [React Flow (`@xyflow/react`)](https://reactflow.dev) |
| 자동 레이아웃 | [Dagre (`@dagrejs/dagre`)](https://github.com/dagrejs/dagre) |
| 화면 캡처 / PDF | [html-to-image](https://github.com/bubkoo/html-to-image) + [jsPDF](https://github.com/parallax/jsPDF) |
| 실시간 동기화 | [Yjs](https://docs.yjs.dev) (CRDT) + `y-websocket` |
| 실시간 서버 | Node.js + `ws` + `y-websocket` |
| 방/권한 API | Node.js + Express + JWT(`jsonwebtoken`) + `bcryptjs` |
| 저장소 | SQLite (Node.js 내장 `node:sqlite`) |

> **왜 Yjs(CRDT)인가?** 여러 명이 동시에 같은 노드를 옮기거나 고쳐도 충돌 없이 자동으로 병합됩니다. 협업 보드에서 가장 어려운 "동시 편집" 문제를 해결합니다. 노드, 연결선, 투표, 채팅, 캘린더는 모두 이 공유 문서에 담겨 실시간으로 동기화됩니다.

## 실행 방법

**Node.js 22.13 이상(24 권장)** 이 필요합니다. 내장 `node:sqlite`를 쓰기 때문에 별도 DB 설치나 네이티브 컴파일은 필요 없습니다. 터미널은 **3개**가 필요합니다.

```bash
# 0. 의존성 설치 (최초 1회)
npm install

# 1. 실시간 동기화 서버  → ws://localhost:1234
npm run server

# 2. 방/권한 관리 API 서버 → http://localhost:3001
npm run api

# 3. 웹 앱 → http://localhost:5173
npm run dev
```

브라우저에서 `http://localhost:5173`에 접속해 회원가입 → 보드 만들기 → 팀원 초대 순서로 시작합니다. 초대받을 팀원도 미리 회원가입이 필요합니다.

### 환경변수

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `JWT_SECRET` | (개발용 기본값) | JWT 서명 키. **운영에서는 반드시 변경** |
| `API_PORT` | `3001` | API 서버 포트 |
| `DB_PATH` | `board.db` | SQLite 파일 경로 |
| `VITE_API_URL` | `http://localhost:3001/api` | 프론트가 호출할 API 주소 |
| `VITE_WS_URL` | `ws://localhost:1234` | 프론트가 접속할 실시간 서버 주소 |

`.env.example`을 참고하세요.

## 데이터 저장

- 보드 내용은 서버의 SQLite(`board.db`)에 보드별로 저장됩니다. 변경 후 약 0.8초 뒤 자동 저장되고, 모든 참여자가 나가면 마지막으로 한 번 더 저장됩니다. **서버를 껐다 켜도 내용이 복원됩니다.**
- 개인 공간은 API 서버를 통해 같은 DB의 `personal_spaces` 테이블에 사용자+보드별로 저장됩니다.
- `board.db`는 `.gitignore`로 커밋에서 제외됩니다.

    ├── nodes/                # WBS·스티커·사진 노드, 투표/댓글 버튼, 실시간 커서
