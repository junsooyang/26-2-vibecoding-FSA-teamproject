# 26-2 바이브코딩 FSA 팀플 · 실시간 협업 보드

팀 프로젝트의 **브레인스토밍 / 마인드맵 / WBS** 작성을 돕는 실시간 협업 보드입니다.
팀장이 방을 만들면 참여자들이 같은 방에 접속해 **노드를 생성하고, 트리를 연결하거나 이동하면 변경 사항이 실시간으로 동기화**됩니다.

## 기술 스택

| 영역 | 사용 기술 |
|------|-----------|
| 프론트엔드 | React 18 + TypeScript + Vite |
| 캔버스 / 노드 UI | [React Flow (`@xyflow/react`)](https://reactflow.dev) |
| 자동 레이아웃 | [Dagre (`@dagrejs/dagre`)](https://github.com/dagrejs/dagre) |
| 실시간 동기화 | [Yjs](https://docs.yjs.dev) (CRDT) + `y-websocket` |
| 실시간 서버 | Node.js + `ws` + `y-websocket` 유틸 |
| 방/권한 관리 API | Node.js + Express + JWT(`jsonwebtoken`) + `bcryptjs` |
| 영속화(저장) | SQLite (Node.js 내장 `node:sqlite`) |

> **왜 Yjs(CRDT)인가?** 여러 명이 동시에 같은 노드를 옮기거나 수정해도 충돌 없이 자동 병합됩니다. 협업 보드의 가장 어려운 "동시 편집" 문제를 해결하는 핵심입니다.

## 실행 방법

터미널 **3개**가 필요합니다. (실시간 서버 / API 서버 / 웹 앱)

### 1. 의존성 설치
```bash
npm install
```

### 2. 실시간 동기화 서버 (터미널 1)
```bash
npm run server
```
`ws://localhost:1234` — 노드/엣지 실시간 동기화 + SQLite 저장 담당.

### 3. 방/권한 관리 API 서버 (터미널 2)
```bash
npm run api
```
`http://localhost:3001` — 회원가입/로그인, 방 생성/초대/권한 담당.

### 4. 웹 앱 (터미널 3)
```bash
npm run dev
```
브라우저에서 `http://localhost:5173` 접속.

### 5. 사용 흐름 확인
1. **회원가입/로그인** 후 **내 보드 목록** 화면 진입
2. **+ 방 만들기** 로 새 보드 생성 (만든 사람이 팀장이 됨)
3. 보드 안의 **멤버 관리** 에서 팀원 아이디로 초대 (팀원도 미리 회원가입 필요)
4. 초대된 팀원이 로그인하면 **내 보드 목록**에 해당 방이 보이고, 입장하면 실시간으로 함께 편집

## 영속화 (데이터 저장)

보드 내용은 서버의 **SQLite 데이터베이스(`board.db`)** 에 방(room)별로 저장됩니다.

- 노드/엣지를 바꾸면 서버가 잠시(약 0.8초) 뒤 Yjs 문서 전체를 DB에 저장합니다.
- 모든 참여자가 방을 나가면 마지막 상태를 한 번 더 저장합니다.
- **서버를 껐다 켜도** 같은 방 이름으로 다시 들어가면 내용이 그대로 복원됩니다.

Node.js 18 이상에 내장된 `node:sqlite` 를 사용하므로 **별도 설치나 네이티브 컴파일이 필요 없습니다.**
DB 파일 위치는 환경변수 `DB_PATH` 로 바꿀 수 있습니다. (`board.db` 는 `.gitignore` 로 커밋에서 제외됩니다.)

```bash
# DB 파일 경로를 바꾸고 싶을 때
DB_PATH=data/myboard.db npm run server
```

## 계정 & 권한

| 역할 | 권한 |
|------|------|
| **팀장 (owner)** | 방 생성자. 멤버 초대/강퇴, 방 삭제, 편집 모두 가능 |
| **참여자 (member)** | 방 입장 및 편집만 가능 (초대/삭제 불가) |

- 로그인 식별자는 **아이디(username)** 입니다. (영문/숫자/밑줄 `_`, 3~20자)
- 인증은 **JWT** 기반이며, 로그인 토큰은 브라우저 `localStorage` 에 저장됩니다.
- 비밀번호는 `bcrypt` 로 해싱되어 저장됩니다 (평문 저장 안 함).
- 방 이름을 입력하면 실시간 동기화용 식별자(slug)가 자동 생성됩니다. 한글 방 이름도 지원합니다.
- 권한 체크는 **서버(API)에서** 수행하므로, 초대받지 않은 사용자는 방 데이터에 접근할 수 없습니다.

### 서버 환경변수

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `JWT_SECRET` | (개발용 기본값) | JWT 서명 비밀키 — **운영에서는 반드시 변경** |
| `API_PORT` | `3001` | API 서버 포트 |
| `DB_PATH` | `board.db` | SQLite 파일 경로 |
| `VITE_API_URL` | `http://localhost:3001/api` | 프론트가 호출할 API 주소 |
| `VITE_WS_URL` | `ws://localhost:1234` | 프론트가 접속할 실시간 서버 주소 |

## 노드 종류

한 보드에서 두 가지 노드를 섞어서 쓸 수 있습니다.

| 종류 | 용도 | 담는 정보 |
|------|------|-----------|
| **아이디어 노드** | 브레인스토밍 / 마인드맵 | 텍스트(라벨)만 |
| **WBS 작업 노드** | 업무 분해 구조(WBS) | 작업명 · 담당자 · 상태(할 일/진행 중/완료) · 진행률(0~100%) · 링크/파일 첨부 · 투표 |
| **사진(이미지) 노드** | 참고 이미지 · 레퍼런스 | 업로드 이미지(최대 3MB) · 캡션 |
| **스티커(포스트잇) 메모** | 자유 메모 · 아이디어 모으기 | 텍스트 · 색상(노랑/분홍/파랑/초록) · 투표 |

WBS 노드는 상태에 따라 테두리/배지 색이 바뀌고(회색→파랑→초록), 진행률 바가 표시됩니다.
상태를 "완료"로 바꾸면 진행률이 자동으로 100%가 됩니다.

### WBS 노드: 완료 체크 & 자료 첨부

- 노드 카드 왼쪽 위의 **체크박스**를 누르면 바로 **완료(done)** 로 전환되고 진행률이 100%가 됩니다. (해제하면 다시 할 일) 완료된 작업은 제목에 취소선이 표시됩니다.
- 편집 패널의 **📎 자료 첨부** 에서 **링크**(URL)나 **파일**(최대 2MB)을 붙일 수 있습니다. 첨부가 있으면 노드에 `📎 개수`가 표시되고, 클릭하면 링크는 새 탭으로 열리고 파일은 다운로드됩니다.
- 첨부 파일은 서버의 Yjs 문서에 함께 저장되므로 **서버를 재시작해도 유지**됩니다.

| 아이디어 노드 추가 | 빈 캔버스를 **더블클릭** |
| WBS 작업 노드 추가 | 상단 툴바의 **+ WBS 작업** 버튼 |
| 스티커 메모 추가 | 상단 툴바의 **+ 메모** 버튼 → 내용 입력 |
| 사진(이미지) 노드 추가 | 상단 툴바의 **+ 사진** 버튼 → 이미지 파일 선택 (최대 3MB) |
| 아이디어 노드 수정 | 노드를 **더블클릭** → 텍스트 입력 |
| WBS 노드 수정 | 노드를 **더블클릭** → 편집 패널(작업명/담당자/상태/진행률/첨부) |
| 메모 내용/색상 변경 | 메모를 **더블클릭**(내용) · 상단 **색상 점** 클릭(색) |
| 작업 완료 체크 | WBS 노드 왼쪽 위 **체크박스** 클릭 |
| 링크/파일 첨부 | WBS 편집 패널의 **📎 자료 첨부** 섹션 |
| 투표하기 | 노드의 **👍 버튼** 클릭 (1인 1표, 다시 누르면 취소) |
| 댓글/의견 남기기 | 노드의 **💬 버튼** 클릭 → 우측 댓글 패널 |
| 개인 공간 열기 | 툴바의 **🗂️ 개인 공간** 버튼 (나만 보는 노트장·파일) |
| 노드 이동 | 노드를 **드래그** (20px 그리드에 스냅) |
| **노드 합치기** | 노드를 **다른 노드 위로 드래그**해서 놓으면 부모-자식으로 연결 |
| 트리 연결 | 노드 가장자리의 **점(handle)끼리 드래그** |
| 노드/엣지 삭제 | 선택 후 `Delete` 키 |
| 자동 정렬(마인드맵) | 툴바의 **자동 정렬 ↔**(좌→우) / **↕**(위→아래) 버튼 |
| **격자(행렬) 정렬** | 툴바의 **격자 정렬 ▦** 버튼 (선택 노드만, 없으면 전체) |

### 실시간 커서

다른 참여자의 마우스 위치가 **이름표가 달린 커서**로 캔버스 위에 실시간 표시됩니다.
각자 줌/팬 상태가 달라도 올바른 위치에 보이도록, 커서 좌표는 화면 좌표가 아닌 **캔버스(flow) 좌표**로 공유됩니다. (Yjs `awareness` 활용 — 영속화되지 않는 임시 상태)

### 자동 레이아웃(마인드맵 정렬)

노드 연결 관계를 따라 **트리 모양으로 자동 정렬**합니다. 정렬 결과(각 노드 위치)는 Yjs로 전파되어 **모든 참여자 화면에 동시에 반영**됩니다.

### 노드 합치기(드래그 연결)

노드를 **다른 노드 위로 드래그**해서 놓으면 두 노드가 **부모-자식으로 연결**됩니다. 주제를 모으거나 트리를 빠르게 만들 때 유용합니다.
- 드래그 중 겹치는 대상 노드에 **초록 점선 테두리 + "여기에 합치기"** 안내가 표시되어 어디에 붙을지 미리 보여줍니다.
- 이미 연결된 노드끼리는 중복/역방향 엣지가 생기지 않습니다.

### 격자(행렬) 정렬 & 그리드 스냅

- 툴바의 **격자 정렬 ▦** 버튼을 누르면 노드들이 **격자(행렬)로 등간격 줄맞춤**됩니다. 노드를 선택해 두면 선택한 노드만, 아무것도 선택하지 않으면 전체가 정렬됩니다. 사진·텍스트 노드를 가지런히 배치할 때 좋습니다.
- 노드를 드래그할 때 **20px 그리드에 스냅**되어 자연스럽게 줄이 맞습니다.
- 정렬 결과는 Yjs로 전파되어 모든 참여자 화면에 동시에 반영됩니다.

### 스티커(포스트잇) 메모

**+ 메모** 버튼으로 포스트잇 스타일 메모를 추가합니다. 자유로운 아이디어 기록이나 회의 메모에 좋습니다.
- 더블클릭으로 내용 수정, 상단의 **색상 점**(노랑/분홍/파랑/초록)으로 색을 바꿀 수 있습니다.
- 다른 노드처럼 드래그/연결/정렬/투표가 모두 가능합니다.

### 투표

WBS 작업 노드와 스티커 메모에는 **👍 투표 버튼**이 있습니다. 어떤 아이디어나 작업을 우선할지 팀이 함께 정할 때 사용합니다.
- **1인 1표**(로그인 username 기준)이며, 다시 누르면 투표가 취소됩니다.
- 득표 수는 Yjs에 저장되어 **모든 참여자에게 실시간 반영**되고, 서버 재시작에도 유지됩니다.

### 노드 댓글 / 의견

각 노드의 **💬 버튼**을 누르면 우측에 댓글 패널이 열립니다. 특정 작업·아이디어에 대한 피드백을 스레드로 남길 수 있습니다.
- 작성자 이름과 시간이 함께 표시되며, **본인이 쓴 댓글만 삭제**할 수 있습니다.
- 댓글은 Yjs에 저장되어 **모든 참여자에게 실시간 공유**되고 서버 재시작에도 유지됩니다.
- 노드 카드의 `💬 개수`로 댓글 유무를 한눈에 볼 수 있습니다.

### 팀원별 개인 공간 (노트장 + 파일)

툴바의 **🗂️ 개인 공간** 버튼으로 **나만 보는** 개인 메모와 파일 보관함을 엽니다.
- **개인 노트장**: 자유 메모 (자동 저장)
- **개인 파일 보관함**: 파일 업로드(최대 2MB)해 보관, 언제든 다시 다운로드
- 이 데이터는 **공유되지 않고**, 내 브라우저에 사용자+방별로 저장됩니다. (`localStorage` — 다른 기기/브라우저에서는 보이지 않음)

### 실시간 마우스 포인터

다른 참여자의 마우스 위치가 **색깔 커서 + 이름표**로 캔버스에 실시간 표시됩니다. (위 "실시간 커서" 참고)
